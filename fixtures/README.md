# Fixtures

Synthetic PPTX files for manual testing and examples. Generated by:

```sh
cargo run -p intern-core --example gen_fixtures
```

| File | Expected violations |
|---|---|
| `clean.pptx` | None — happy-path baseline |
| `two_column.pptx` | `COLUMN_LEFT_EDGE` — left-column X edges drift by 10 and 30px |
| `grid_h_spacing.pptx` | `GRID_H_SPACING`, `GRID_COL_LEFT` — horizontal gap inconsistency across rows |
| `grid_row_top.pptx` | `GRID_ROW_TOP`, `GRID_V_SPACING` — one element shifted down 10.5px in its row |

> Shape names in output appear as `Shape N` — ppt-rs auto-assigns names and does not expose a way to override them.
